1. Executive Summary & Project Abstract

Tourex Himalaya is an enterprise-grade tourism management and travel reservation platform designed specifically for high-altitude Himalayan circuits including Himachal Pradesh (Manali, Spiti Valley, Dharamshala, Kasol, Kinnaur) and Uttarakhand (Rishikesh, Chardham Yatra, Mussoorie, Nainital).

Traditional travel agency websites frequently struggle with sluggish load speeds, disjointed inquiry workflows, manual booking tracking, lack of live mountain route transparency, and delayed receipt generation. Tourex Himalaya addresses these shortcomings by unifying:

  • Client-Side Performance: An ultra-lightweight Single Page Application (SPA) powered by React 18 and Vite 6 delivering sub-second load times and client-side page transitions.
  • Cloud Database Persistence: Instant bi-directional synchronization with an enterprise PostgreSQL database via Supabase BaaS with strict Row Level Security (RLS).
  • Multi-Channel Payment Experience: A seamless checkout flow supporting Google Pay, PhonePe, Paytm, UPI QR, and Credit/Debit Cards with automated 25% token advance calculation.
  • Instant GST Tax Billing: An in-browser printable and offline-downloadable Tax Invoice engine compliant with Indian GST & HP Tourism regulations (SAC 998555).
  • Live Road & Weather Advisories: Dynamic safety condition reporting for critical mountain passes (Atal Tunnel, Rohtang Pass, and Chardham corridors).
Key Project Milestone: Complete migration from static UI mockups into an interactive, end-to-end production web application connected to remote cloud databases and synchronized with remote GitHub version control.

3. Database Architecture & Schema Design

The database resides on a high-availability PostgreSQL cluster managed by Supabase (Project ID: kdsacywhjmzkogqtnxwt). The database is structured into three primary tables adhering to 3NF (Third Normal Form) with strict field typing and Row Level Security (RLS) constraints.

3.1 Table: public.bookings

Stores confirmed traveler bookings, route logistics, calculated price totals, advance tokens, and payment audit logs.

Column Name Data Type Constraints Description
id BIGINT PRIMARY KEY, GENERATED ALWAYS AS IDENTITY Internal surrogate primary key.
booking_id TEXT UNIQUE, NOT NULL Human-readable booking reference (e.g., TXH-2026-891024).
full_name TEXT NOT NULL Full legal name of the primary traveler.
phone TEXT NOT NULL WhatsApp contact number for coordination and alerts.
email TEXT NULLABLE Customer email address for PDF voucher dispatch.
destination TEXT NOT NULL Selected tour destination or custom circuit.
service_type TEXT DEFAULT 'tour' Categorization (package tour, car rental, camping).
check_in DATE NULLABLE Tour start date.
check_out DATE NULLABLE Tour conclusion date.
guests TEXT NOT NULL Group configuration (e.g., "2 People (Couple / Friends)").
pickup_city TEXT NOT NULL Departure point (e.g., Delhi, Chandigarh, Dehradun).
discount_amount NUMERIC DEFAULT 0 Promotional coupon deduction in INR.
total_payable NUMERIC NOT NULL Total package cost including GST.
advance_token NUMERIC NOT NULL 25% confirmation token paid through gateway.
status TEXT DEFAULT 'advance_paid' Booking status lifecycle indicator.
created_at TIMESTAMPTZ DEFAULT NOW() System audit timestamp of booking creation.

3.2 Table: public.inquiries

Captures custom trip customization inquiries, corporate quotes, and contact inquiries.

Column Name Data Type Constraints Description
id BIGINT PRIMARY KEY, IDENTITY Primary inquiry identifier.
name TEXT NOT NULL Inquirer's full name.
phone TEXT NOT NULL Contact phone number.
destination TEXT NOT NULL Preferred circuit or customized location.
travel_dates TEXT NULLABLE Tentative travel window.
travelers_count INTEGER DEFAULT 2 Total passenger headcount.
budget_range TEXT NULLABLE Expected budget (Standard, Deluxe, Luxury).
vehicle_preference TEXT NULLABLE Vehicle choice (Innova, Thar, Tempo Traveller).
status TEXT DEFAULT 'pending' Inquiry lifecycle state (pending, contacted, closed).
created_at TIMESTAMPTZ DEFAULT NOW() Creation timestamp.

4. Key Modules & Functional Architecture

4.1 Interactive 3-Step Booking Modal (BookingModal.jsx)

The core transaction engine guides tourists through three orchestrated steps:

  • Step 1 (Traveler Details): Validates full name, phone number, destination, dates, pickup location, and applies promo codes (e.g., HIMALAYA10 for 10% off or FIRSTTRIP for 15% off).
  • Step 2 (Payment Gateway): Integrates the Skillshare-inspired payment interface allowing immediate simulated checkout across multiple Indian payment rails.
  • Step 3 (Voucher & Confirmation): Asynchronously pushes the payload into Supabase, displays the confirmed booking reference, and exposes direct WhatsApp concierge handoff along with the Tax Invoice download trigger.

4.2 Multi-Channel Payment Gateway (PaymentGateway.jsx)

Designed to replicate modern checkout interfaces (Skillshare / Razorpay), this component enables customers to choose between:

  • UPI Direct: Google Pay, PhonePe, and Paytm one-click deep links.
  • Dynamic QR Code: Simulated on-screen Bharat QR scanner with live verification animation.
  • Credit / Debit Cards: Standard card fields with live formatting, brand detection (Visa/Mastercard/Amex/RuPay), and SSL verification badges.
  • Financial Calculation: Computes the 25% confirmation advance token while maintaining the 75% balance due on arrival.

4.3 Official GST Tax Invoice & Bill Engine (BillReceiptModal.jsx)

Generates an official, legal Indian Tax Invoice formatted for tour operators:

  • Legal Details: Tourex Himalaya, HP Tourism Reg: HP-TRV/MNL/2026/894, GSTIN: 02AAACT1940E1Z5, SAC Code: 998555.
  • Tax Breakdown: Itemizes the Base Package Cost, Promotional Discount, 5% Tour Operator GST (2.5% CGST + 2.5% SGST), Token Paid Today, and Balance on Arrival.
  • Dual Export Engine: Provides both a browser print stylesheet (saving crisp A4 PDFs via window.print()) and a direct offline .html file download mechanism.

4.4 Split-Screen Authentication System (AuthModal.jsx)

Implements a clean split-screen modal inspired by premium travel portals. Features a scenic Himalayan mountain visual on the left pane and an interactive Sign In / Sign Up form on the right pane supporting Google single sign-on and credential authentication with password reveal toggles.

4.5 Dynamic Custom Trip Planner (CustomTripPlanner.jsx)

An interactive estimation widget that lets users configure destination, days, travelers, and accommodation class, dynamically generating an instant cost estimate and saving custom quote inquiries directly into the database.
